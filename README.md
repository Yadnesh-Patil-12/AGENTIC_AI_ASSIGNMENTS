# OOMSD Lab Assignments

## Object-Oriented Modeling and System Design

This repository contains the lab assignments for **Object-Oriented Modeling and System Design (OOMSD)**. It covers object-oriented analysis and design, GRASP and SOLID principles, UML modeling, database design, ORM, software architecture, design patterns, and API design.

## 🎯 Objectives

- Understand object-oriented analysis and design.
- Apply GRASP and SOLID principles.
- Create UML diagrams for real-world software systems.
- Design database schemas and understand ORM.
- Explore layered and microservices architectures.
- Apply software design patterns.
- Design and document REST APIs.
- Prepare comprehensive system design documentation.

## 📚 Lab Assignments

### Assignment 1: GRASP Principles for Online Course Management System

**Aim:** Identify objects, responsibilities, and relationships using GRASP principles.

**Tasks:**
- Identify objects and classes in an online course management system.
- Assign responsibilities using GRASP principles.
- Prepare a responsibility table.
- Create Class-Responsibility-Collaborator (CRC) cards.
- Develop a preliminary class diagram.

**Concepts:** GRASP, Information Expert, Creator, Controller, Low Coupling, High Cohesion, CRC Cards.

### Assignment 2: Smart Library Management System Using SOLID Principles

**Aim:** Develop UML diagrams for a smart library management system using SOLID principles.

**Tasks:**
- Create a use case diagram.
- Develop a class diagram.
- Create a sequence diagram for the book borrowing process.
- Identify classes, actors, and relationships.
- Apply SOLID principles to the system design.

**Concepts:** UML, Use Case Diagram, Class Diagram, Sequence Diagram, SOLID Principles.

### Assignment 3: Database Schema Design for E-Commerce Order Processing

**Aim:** Design and normalize a database schema from an object model.

**Tasks:**
- Identify entities and relationships.
- Design an Entity-Relationship (ER) diagram.
- Normalize the database schema.
- Convert the ER model into relational tables.
- Map object classes to database tables.

**Concepts:** ER Modeling, Database Normalization, Relational Schema, Primary Keys, Foreign Keys, Class-to-Table Mapping.

### Assignment 4: Object-Relational Mapping (ORM) Patterns

**Aim:** Explore ORM patterns and demonstrate the mapping of objects to relational databases.

**Tasks:**
- Study ORM mapping patterns.
- Prepare an ORM mapping file or pseudocode.
- Create a UML diagram showing entity relationships.
- Explain the mapping logic in a short report.
- Demonstrate the relationship between classes and relational tables.

**Concepts:** ORM, Entity Mapping, Object-Relational Impedance Mismatch, Entity Relationships, Database Persistence.

### Assignment 5: Service Interactions and API Architecture for Online Food Delivery

**Aim:** Design service interactions and API architecture for an online food delivery system.

**Tasks:**
- Create a sequence diagram for the food ordering process.
- Develop a component diagram showing system services.
- Identify API endpoints and HTTP methods.
- Document request and response formats.
- Explain interactions between ordering, restaurant, payment, and delivery services.

**Concepts:** REST APIs, HTTP Methods, JSON, Sequence Diagrams, Component Diagrams, Service Communication.

### Assignment 6: Design Patterns for a Banking Transaction System

**Aim:** Apply software design patterns to a banking transaction system.

**Tasks:**
- Identify suitable design patterns for banking operations.
- Apply the Factory pattern to object creation.
- Apply the Observer pattern to transaction notifications.
- Create UML class diagrams showing pattern integration.
- Develop pseudocode demonstrating the implementation.

**Concepts:** Factory Pattern, Observer Pattern, UML Class Diagrams, Object Creation, Event Notification, Extensibility.

### Assignment 7: Layered and Microservices Architecture for a Smart Healthcare System

**Aim:** Design a healthcare system using layered or microservices architecture.

**Tasks:**
- Identify major components and services.
- Create a layered architecture or service-oriented architecture diagram.
- Develop a deployment diagram.
- Explain the responsibilities of architectural layers or services.
- Justify the selected architecture based on scalability, maintainability, and security.

**Concepts:** Layered Architecture, Microservices, Service-Oriented Architecture, Deployment Diagrams, Scalability, Security.

### Assignment 8: Integrated System Design

**Aim:** Prepare a complete system design document integrating object-oriented modeling, database design, API design, and software architecture.

**Tasks:**
- Define system requirements and identify major components.
- Develop the necessary UML diagrams.
- Include database and relational schema design.
- Document API endpoints and service interactions.
- Present the selected software architecture.
- Prepare a complete design document and presentation slides.

**Concepts:** UML, Database Design, REST APIs, System Architecture, Technical Documentation, Design Integration.

- Compare software architecture approaches.
